## What this repo is (and is not)

- **This repo:** the generic, MIT-licensed Chip Chat **engine** — `scripts/chip/` (CLI, spend gates,
  mock mode, MemPalace lite), `scripts/chip_relay/` (Discord relay, routing, delegate, health port),
  generic docs, `systems/acme-example`, shared tests.
- **Not this repo:** the homelab pack, deploy compose, operator secrets, monitoring/plex/self-heal
  plugins. Those live in the private `a1ly404/chip-chat-razzorstack-plugin` (renamed from
  `a1ly404/chip-chat` on 2026-10-08).
- **This repo is public** (MIT, created 2026-10-08 from a one-shot `tools/engine_export/` export).
  Treat every commit here as publishable: no operator ids, no packs, no secrets.

**Production does not run from this repo.** The live `chip-relay` / `chip-scheduler` containers are
built from the plugin repo. An engine change reaches prod only when the plugin adopts a pinned release
and rebuilds — so "merged here" is not "live".

## Boundaries that already bit people

1. **Do not reintroduce operator config here.** Packs load via `CHIP_SYSTEM_PACK` / `CHIP_PACK_DIR` /
   `CHIP_PLUGINS`. Personas, rooms, channel law and tools manifest for the homelab are pack data.
2. **Mock mode is the default for agent work:** `CHIP_CHAT_MOCK=1` or `--mock`. Live OpenRouter needs
   an explicit GO; spend WARN is $5.00 and the hard stop is $10.00/month.
3. **Tests must never post to live Discord.** Relay tests are mocked; keep them that way.
4. **This repo's history is world-readable.** Do not paste operator receipts, webhook URLs, snowflakes
   or `.env` values into code, docs, or test fixtures. Use pack `identity` JSON in private packs.
5. **Commit style:** reviewable slices, `Agent: <name>` trailer, reference the tracker without
   auto-closing words (`Refs RAZ-xxx`, never `Fixes`/`Closes`).
